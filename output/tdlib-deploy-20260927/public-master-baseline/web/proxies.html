❓ ¿Cómo funciona?

Para desplegar un proxy MTProto necesitas un Puerto libre en tu servidor y un Secret Hex.
• Puedes generar un Secret aleatorio de 32 caracteres (0-9, a-f).
• Si usas Docker, el botón de escaneo buscará contenedores con nombres que incluyan "proxy" o "mtproto".
• Una vez creado, usa el enlace tg://proxy?server=TU_IP&port=PUERTO&secret=SECRET para conectarte.
